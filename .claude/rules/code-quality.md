# Code Quality

## Anti-defaults (counter common Claude tendencies)

- No premature abstractions. Three similar lines beats a helper used once.
- Don't add features or improvements beyond what was asked.
- Don't refactor adjacent code while fixing a bug.
- No dead code or commented-out blocks. Git has history.
- WHY comments, never WHAT. If code needs a "what" comment, rename instead.
- Doc comments at package and exported-symbol boundaries only, not every internal function.

## Naming — Go (both modules)

- Standard Go style: `MixedCaps`, never underscores. Initialisms stay uppercase: `ID`, `URL`, `SQL`,
  `HTTP`, `DLQ`, `HLC` — so `orderID` and `sequenceEngineKey`, never `orderId`.
- Exported identifiers carry the package as context: `dag.Node`, not `dag.DAGNode`.
- Files: lowercase, no separators where possible (`valuation.go`, `errclass.go`); `_test.go` suffix
  for tests. Directories: lowercase single words.
- Constructors: `New*`. Converters: `To*`. Predicates: `Is*` / `Has*`.
- Errors: `ErrFoo` for sentinels, `FooError` for types. Error strings are lowercase, no punctuation.

## Naming — frontend (`frontend/`)

- Components: PascalCase files (`Ledger.tsx`). Hooks: `use*` (`useEventBuffer.ts`). Utilities and
  other non-component modules: camelCase or kebab-case (`config.ts`).
- Booleans: `is` / `has` / `should` / `can` prefix. Handlers: `handle*` internal, `on*` as props.
- Named exports over default. One component per file.

## Code Markers

`TODO(author): desc (#issue)` for planned work. `FIXME(author): desc (#issue)` for known bugs.
`HACK(author): desc (#issue)` for ugly workarounds (explain the proper fix). `NOTE: desc` for
non-obvious context. Owner and issue link required. Never `XXX`, `TEMP`, `REMOVEME`.

## File Organization

- Go imports in three groups separated by blank lines: stdlib, external, `omniflow/...`. `gofmt`
  sorts within groups; it will not regroup for you.
- Go file order: types, constructors, exported methods, unexported helpers in call order.
- Never edit `*.pb.go` by hand. They are generated by `buf` and committed on purpose (see `BUILD.md`);
  change the `.proto` and regenerate.
